# prompts/templates — templates de prompt

**O que é:** espaço reservado para templates tipados, versionados e avaliados
(ex.: "resuma este documento em N tópicos").

**Estado:** vazio de propósito. Ao criar um template: um arquivo por template,
com cabeçalho dizendo variáveis, versão e como foi avaliado. Sem segredo.

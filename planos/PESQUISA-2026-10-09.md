## IA que não passa no servidor

Chrome e Edge, só desktop e só máquina que aguente (documentação Chrome, atualizada em 2026): Translator, Language Detector, Summarizer, Writer, Rewriter, Prompt API. O modelo é o Gemini Nano **no aparelho**. Token da casa: R$ 0.

Limite honesto, escrito pela própria doc do Chrome:

- Não roda no celular (Android / iOS) nem no ChromeOS comum.
- Prompt, resumo, writer e rewriter pedem máquina forte (GPU com mais de 4 GB, ou CPU com 16 GB de RAM) e espaço livre grande no perfil.
- Translator e detector de idioma: desktop, ainda assim não é o telefone.

Uso no KAZER: se `Summarizer` (ou o equivalente) existir na janela, o resumo longo sai lá. Se não existir, continua o Brain (Groq / Hugging Face), que já está no ar. **Não trocar o Brain por isso.**

### Armadilha de licença (importante)

`@imgly/background-removal` tira fundo no browser e custa R$ 0 de API, mas a licença publicada é **AGPL-3.0**. Colar isso dentro do KAZER (código proprietário, `UNLICENSED`) obriga a abrir o fonte ou a comprar licença comercial com a img.ly. Não usar.

Modelo RMBG da Bria e parecidos costumam ser **não comerciais**. Não usar no produto que vai cobrar Pro.

Caminho limpo: MediaPipe para pessoa. Objeto genérico espera um modelo com licença que autorize app fechado, ou a chave BYOK de um provedor que o usuário paga.

## Ordem para construir (quando for código)

Cada item nasce como módulo novo. O composer do chat fica.

1. **Bancada PDF** — juntar, separar, girar. É a busca que já tem audiência e o diferencial é “não subi meu contrato”.
2. **Foto** — comprimir + paleta. Leve, sem modelo.
3. **Recorte de pessoa** — MediaPipe, com aviso de primeira carga do modelo.
4. **Deck e cartão** — HTML que o Brain já sabe escrever, export com selo no grátis.
5. **OCR** — nota e print, língua `por`.
6. **Atalho Chrome** — resumo nativo só se a API existir; senão o Brain.

O que o Pro passa a vender, sem GPU nova:

- exportação sem selo;
- kits guardados na conta (o banco já existe; arquivo pesado continua no aparelho, IndexedDB);
- pack MEI (proposta + contrato modelo + cartão) como extra avulso no mesmo Pix.

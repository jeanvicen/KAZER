# Catálogo de ferramentas

Pesquisa de mercado 2026 (ChatGPT, Claude, Perplexity, Canva Magic Studio, Gamma, Recraft, Grok Skills) mostra o que as pessoas pagam. O KAZER entrega o equivalente **sem aluguel de GPU**, sempre ao lado do que já está no ar.

## Já no produto

| Ferramenta | Usuário ganha | Custo para a casa |
|---|---|---|
| Conversa | Brain (Groq / Hugging Face), Markdown, sessão | Plano livre dos providers |
| Anexos | JPEG, PNG, WebP, GIF, PDF, DOCX, texto | Parse no servidor |
| WebKazer | Pesquisa, leitura, síntese com citações | Groq + fontes públicas |
| Workspace | Tarefas, progresso, custo, repos | Já no painel do raio |
| GitHub | OAuth e contexto do código | OAuth, sem taxa |
| Drive + MCP | Arquivos e plugins com segredo cifrado | Backend |
| PWA | Ícone na tela inicial | Sem loja, sem 30% |

# Kazer — preparação para Android

A versão atual do Kazer é um PWA instalável pelo navegador. Para gerar uma versão Android nativa, será necessário empacotar a aplicação, configurar ícone adaptativo, nome do pacote, assinatura de release, política de privacidade, declaração de dados e screenshots.

Os ícones compartilhados ficam em `../icons/kazer-192.png` e `../icons/kazer-512.png`. O material de loja está em `../play-store/store-listing.md`.

Não há APK ou AAB neste diretório ainda; esses arquivos só devem ser gerados depois de definir o projeto nativo e a assinatura de distribuição.

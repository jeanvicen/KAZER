# Kazer — preparação para iOS

A versão atual do Kazer pode ser instalada como PWA no Safari usando **Adicionar à Tela de Início**. Para uma publicação nativa na App Store, será necessário gerar um projeto iOS, configurar assinatura e certificados Apple, preparar screenshots para os tamanhos exigidos, política de privacidade, informações de suporte e conta Apple Developer.

O manifest e os ícones compartilhados ficam em `../manifest.webmanifest`, `../assets/kazer-logo.svg` e `../icons/`.

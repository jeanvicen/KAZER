# Quality bar — o que separa um relatório confiável de um medíocre

## Checklist por resposta

### Estrutura
- [ ] A resposta direta vem **primeiro** (2 parágrafos no máximo)
- [ ] O método vem depois, não antes
- [ ] Há uma seção de "o que isso significa" para o usuário
- [ ] Não há "Resumo" seguido de "Introdução" dizendo a mesma coisa

### Evidência
- [ ] Toda afirmação factual relevante tem citação
- [ ] As queries foram distintas entre si (não sinônimos)
- [ ] Pelo menos uma fonte primária
- [ ] Divergências entre fontes estão declaradas
- [ ] Dado ausente está marcado como ausente

### Citação
- [ ] Numeração sequencial por ordem de aparição
- [ ] Máximo 10 inline
- [ ] Fonte principal e de apoio são distinguíveis
- [ ] O trecho no painel é o trecho **real** usado

### Painel de fontes
- [ ] 5+ fontes
- [ ] Título, domínio, favicon, trecho e link em cada uma
- [ ] Ordem por ordem de citação

### Honestidade
- [ ] "Não encontrei" aparece quando aplicável
- [ ] Dados de 2025+ são rotulados temporalmente
- [ ] Opinião é marcada como opinião
- [ ] O relatório lista o que **não** foi coberto

## Teste dos 5 segundos

Leia só os primeiros 5 segundos da resposta. Se o leitor não sabe o que
responder, a resposta está mal estruturada — não importa o quanto a segunda
seção seja boa.

## Teste do cético

Escolha a citação mais importante e verifique: a fonte realmente diz isso?
Citações que não sustentam a afirmação são pior que ausência de citação,
porque destroem a confiança em todas as outras.

## Sinais de alerta

| Sinal | O que indica |
|---|---|
| Todas as fontes do mesmo domínio | Viés de domínio — procure contraponto |
| Todas as fontes da mesma data | Possível campanha de imprensa |
| Nenhuma fonte primária | Tema mal documentado; diga isso |
| 15+ citações inline | Resposta ilegível — corte para as 5 que importam |
| Resposta sem nenhum número | Opinião, não pesquisa |

# Hierarquia de fontes

Nem toda fonte vale o mesmo. Esta é a ordem em que o KAZER confia.

## Tier 1 — Primária

A fonte **é** o fato: documentação oficial, registro público, norma,
especificação, paper, base de código, dado bruto.

- Docs do provedor, changelog, API reference
- Registro oficial (Diário Oficial, Junta Comercial, SEC, CVM)
- Norma (ISO, ABNT, RFC, IEEE)
- Paper com DOI, repositório oficial
- Planilha ou dataset publicado pela própria entidade

**Quando usar:** sempre que existir. É o que sustenta uma citação forte.

## Tier 2 — Secundária

Reputação editorial, metodologia explícita, autor identificável.

-JORNAIS e veículos especializados
- Análise técnica de engenharia com dados próprios declarados
- Pesquisa de mercado com metodologia publicada

**Quando usar:** quando não há fonte primária, ou para contexto e tendência.

## Tier 3 — Terciária

Sem curadoria editorial clara.

- Blog técnico pessoal
- Thread de fórum, comentário em issue
- Conteúdo de vendor (página de marketing)

**Quando usar:** **apenas** como pista de pesquisa. Nunca como citação de
uma afirmação factual. Se um blog é a única fonte, o honesto é dizer: "Encontrei
apenas referências secundárias; o valor oficial não está publicado."

## Tier 4 — Excluída

Descarte de cara:

- Conteúdo republished sem atribuição
- Listas "top N" sem critério
- Conteúdo gerado em massa ( farms de SEO)
- Postagens em rede social
- Sites com reviewed há anos e sem data

## Conflito entre fontes

Quando Tier 1 e Tier 2 discordam, **Tier 1 vence** — exceto se a Tier 1
estiver desatualizada (data verificável). Registre o conflito na resposta:

> A documentação oficial define X[2], mas a análise mais recente reporta
> Y[4]. A diferença provavelmente é de data — a documentação é de março.

## Data

- Toda citação carrega a data de publicação.
- Dado com mais de 18 meses é apresentado como histórico, nunca como atual.
- "Em 2025, o preço era X" é melhor que omitir a informação temporal.

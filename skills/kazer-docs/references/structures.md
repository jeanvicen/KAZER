# Estruturas por tipo de documento

## Relatório executivo
```
# Título
> Uma linha com a conclusão principal.

## Resumo executivo
3–5 frases: situação, impacto, recomendação.

## Situação
Contexto factual com dados.

## Análise
 achados, um subtítulo por achado.

## Riscos e limitações

## Recomendação
Ação, responsável, prazo.
```

## Proposta comercial
```
# Proposta — [projeto] para [cliente]
> [valor] · [prazo] · [entregáveis]

## Resumo executivo

## Contexto do cliente
Use o que o cliente já disse. Não invente dor.

## Escopo
O que está incluso — e, principalmente, o que NÃO está.

## Entregáveis
Tabela: item, formato, prazo.

## Investimento
Tabela de preços, com a opção destacada.

## Prazo e marcos

## Riscos e limitações

## Próximos passos
1–3 ações com dono e prazo.
```

## Ata de reunião
```
# Ata — [assunto] · [data]
## Participantes
## Pauta
1. [item] — [decisão]
## Decisões
| Decisão | Quem | Prazo |
## Pendências
| Ação | Responsável | Prazo |
```

## Contrato / revisão
```
# [Tipo] — [partes]
> Baseado em [referência], revisado em [data].

## Cláusula 1 — [nome]
Texto. Subcláusulas numeradas. Referência cruzada quando aplicável.

## Cláusula 2 — ...

## Glossário
Termos técnicos definidos.
```

## README / documentação técnica
```
# [Projeto]
Uma frase do que é.

## Instalação
## Uso
## Configuração
## Arquitetura
## Desenvolvimento
## Licença
```

## Especificação (RFC / PRD)
```
# [Nome]
## Contexto e problema
## Objetivos e não-objetivos
## Usuários
## Solução proposta
## Alternativas consideradas
## Impacto
## Riscos
## Métricas de sucesso
## Rollout
## Questões em aberto
```

## Regra comum a todos

**Toda seção existe porque alguém precisa dela.** Se ninguém vai ler, corte.
O resumo executivo existe porque o leitor pode ter 2 minutos.

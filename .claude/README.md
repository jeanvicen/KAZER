# .claude — instruções para agentes (Claude Code)

| Pasta | Conteúdo |
|---|---|
| `skills/` | Skills do projeto: cada pasta tem um `SKILL.md` com nome, descrição, checklists e antipadrões |

| Skill | Use quando |
|---|---|
| `kazer-art-direction` | desenhar ou revisar qualquer tela |
| `kazer-design-system` | mexer em CSS, componentes e estados |
| `kazer-frontend-quality` | escrever JavaScript do front e fazer QA no navegador |
| `kazer-creative-studio` | trabalhar no Studio |
| `kazer-agent-engineering` | adicionar capacidade, ferramenta ou provedor |
| `kazer-supabase-security` | contas, migrações, RLS, cotas |
| `kazer-memory-engineering` | memória de longo prazo |
| `kazer-scale-performance` | custo, concorrência, carga |
| `kazer-release-qa` | antes de commit, merge ou "pronto" |

As skills descrevem o KAZER **como ele é**; mudou a regra, mude a skill no mesmo commit.

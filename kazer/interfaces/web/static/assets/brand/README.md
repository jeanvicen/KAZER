# brand — logo e ícones do KAZER

**O que é:** o símbolo do KAZER (cabeça do alien com colar dourado) nos formatos
que navegador e celular pedem.

| Arquivo | Uso |
|---|---|
| `mark.svg` | Símbolo principal (fundo claro/geral) |
| `mark-dark.svg` | Variante para fundo escuro |
| `favicon.svg` | Ícone da aba |
| `apple-touch-icon.png` | Ícone ao salvar na tela inicial do iPhone |
| `icon-192.png`, `icon-512.png` | Ícones do app instalado (manifest) |
| `icon-maskable-512.png` | Ícone adaptável do Android (área segura) |

Regras de uso da marca: `docs/brand.md`. Trocou um ícone? Suba a versão do cache em `static/sw.js`.

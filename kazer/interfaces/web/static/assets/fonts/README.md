# fonts — fontes da interface

**O que é:** fontes servidas pelo próprio site (sem Google Fonts, sem rastreio).

| Arquivo | Uso |
|---|---|
| `inter-latin-wght.woff2` | **Inter** (peso variável): toda a interface |
| `grenze-gotisch-500.woff2` | **Grenze Gotisch**: só o nome "KAZER" |
| `OFL-Inter.txt`, `OFL.txt` | Licenças (SIL Open Font License 1.1) — mantenha junto |

Fontes dos **PDFs** ficam em `kazer/assets/fonts/`.

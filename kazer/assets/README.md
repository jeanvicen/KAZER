# kazer/assets — arquivos que o servidor usa

**O que é:** recursos binários lidos pelo **servidor** (não pelo navegador).

| Item | Para que serve |
|---|---|
| `fonts/` | Fontes Liberation usadas por `kazer/chat/documents.py` para montar PDFs (documentos A4 e slides 16:9) |
| `__init__.py` | Permite achar a pasta como pacote |

Arquivos do **site** (CSS, JS, ícones, fontes da interface) ficam em
`kazer/interfaces/web/static/assets/`.

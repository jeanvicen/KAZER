# kazer/assets/fonts — fontes dos PDFs

**O que é:** fontes embutidas nos PDFs que o KAZER gera no servidor
(`kazer/chat/documents.py`). Assim o PDF fica igual em qualquer aparelho.

| Arquivo | Uso |
|---|---|
| `LiberationSans-Regular.ttf` | Texto normal |
| `LiberationSans-Bold.ttf` | Títulos e negrito |
| `LiberationSans-Italic.ttf` | Itálico |
| `LiberationMono-Regular.ttf` | Blocos de código |
| `LICENSE.md` | Licença das fontes (SIL Open Font License) |

**Cuidados:** não troque por fonte sem licença livre para redistribuição.
Mantenha o `LICENSE.md` junto.
